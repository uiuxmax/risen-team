DejaVu Sans (RisenSans.ttf / RisenSans-Bold.ttf)
================================================

Fonts are embedded into exported PDF files so Ukrainian (Cyrillic) text is
rendered correctly on any computer, even if the font is not installed there.

Only the glyphs that are actually used are embedded in each exported PDF.
